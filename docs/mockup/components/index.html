Dalam tombol dan aksi

Aturan pemakaian

  • Ukuran bawaan 20px bila class ukuran tidak ditulis.
  • Gunakan `icon-sm` untuk sidebar dan aksi di dalam tabel.
  • Gunakan `icon-lg` untuk ikon utama di page header.
  • Ikon dekoratif wajib memakai `aria-hidden="true"`.
  • Hindari mencampur ukuran berbeda dalam satu baris aksi.
  • Warna ikon mengikuti makna status, bukan sekadar hiasan.

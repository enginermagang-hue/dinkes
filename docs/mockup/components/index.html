Aturan Pemakaian

  • Warna primer hanya untuk aksi utama dan tautan.
  • Status memakai warna semantik, bukan warna brand.
  • Ukuran ikon selalu memakai class icon-*.
  • Semua komponen harus berfungsi tanpa JavaScript untuk konten inti.
  • Gunakan satu pola penutupan (backdrop, Escape, tombol X).
  • Data pada katalog bersifat dummy dan tidak tersimpan.
